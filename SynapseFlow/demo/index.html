SynapseFlow

Compile natural language into a DAG, review destructive stages, then run ready work in parallel across targets.

See the terminal GitHub

NL → DAG → Parallel

Natural language

“Discover services on web-01 and db-02, restart the spooler, then verify health.”

→

Compiled DAG

S0 Discover-Services
S1 Restart-Spooler
S2 Verify-Health
→

Parallel fanout

Wave A web-01 · discover db-02 · discover
Wave B web-01 · spooler * · verify

Terminal samples

# PowerShell 7 — fictional hosts only
Import-Module ./src/SynapseFlow/SynapseFlow.psd1

$plan = New-SynapsePlan -Intent 'discover, restart spooler, verify health' `
  -Targets web-01,db-02
# PlanId=… Status=Draft Stages=3

$plan = $plan | Confirm-SynapsePlan -ApproveDestructive
# Reviewed=True Status=Reviewed

$flow = Start-SynapseFlow -Plan $plan -MaxParallelStages 2 -Simulation
# FlowId=… Status=Succeeded Simulation=True

$flow | Export-SynapseReport -Path ./report.json
# Redacted JSON written — no telemetry

Why SynapseFlow

Catalog allowlist

Only shipped Catalog stages run. Unknown names are rejected.

Human review gate

Destructive stages require -ApproveDestructive before start.

Zero telemetry

Plans stay in your session. MIT licensed, open source.
