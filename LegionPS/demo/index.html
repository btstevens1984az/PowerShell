Built for safe scale

One job: parallel playbooks without open-ended script execution.

⚡

Parallel fan-out

Throttle-limited ForEach-Object -Parallel across targets like web-01, db-02, and app-03.

🛡

Playbook allowlist

Only scripts under Playbooks/ run. Arbitrary paths are refused at the gate.

🔏

Signed job packs

SHA256 of playbook content on every job; optional HMAC with an ephemeral TEMP key.

🤖

LLM-native plans

JSON-serializable plans with risk, rationale, and DryRun defaults for agent workflows.

🎭

Simulation mode

Mock remoting offline so demos and CI work without a live fleet.

🌫️

Redacted exports

Partial hostname masking and secret-pattern stripping before you share summaries.

Fictional hosts only — Simulation keeps you offline and safe.
