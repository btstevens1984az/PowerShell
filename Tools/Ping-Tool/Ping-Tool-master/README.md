
## PowerShell Ping Tool ##

Power-Ping is a PowerShell Ping utility with a clean and simple GUI.


**Requirements:**

 1. Once downloaded you will most likely need to unblock it. 
	 2. Right-Click
	 3. Properties
	 4. Select “Unblock” at the bottom and save. 
 5. PowerShell 2.0 must be installed. 
 6. The text file containing the list of machines to contact must contain one machine per line. 

**Features:**

 1. Power-Ping supports a .txt file that contains a list of machines for it to ping. Simply use the handy built in file browse to select that file and then hit Start-Ping! 
 2. The tool allows you to select the   refresh interval for the tool to re-ping the machines. The interval can be set as low as 10 seconds and as high as 60 in increments of 5.
 3. The tool highlights any failed machines in red.
